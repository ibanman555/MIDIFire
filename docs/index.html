Quick setup

From download to first message.

MIDIFire works with physical MIDI interfaces and Windows virtual MIDI ports, including Bome MIDI Translator ports.

  1. 1

    Install

    Download the .streamDeckPlugin file and double-click it.

  2. 2

    Add the action

    Drag MIDIFire → Fire MIDI onto a Stream Deck key.

  3. 3

    Choose a port

    Select the hardware or virtual Windows MIDI output.

  4. 4

    Fire

    Configure a message and press the key to send it.

FAQ

Common questions

Can Stream Deck send MIDI on Windows?

Yes. MIDIFire adds a native Stream Deck action that sends standard MIDI, raw MIDI, and SysEx through a selected Windows MIDI output.

Does it work with virtual MIDI ports?

Yes. Bome and other Windows virtual MIDI outputs appear beside physical MIDI interfaces in the output menu.

Can it send a message on key release?

Yes. Notes can send Note Off, CC can send zero, and raw mode can send a separate release message.

Is MIDIFire free?

Yes. MIDIFire is free and open source under the MIT License.
